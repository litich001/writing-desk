# 截图

> 打包时这台开发机没有可见桌面窗口，`browser.screenshot` 拍不了，
> 所以仓库里没有图 —— **不放占位图充数**。
>
> 想补图，按下面这份清单在自己机器上截，存到 `docs/shots/`，
> 然后把 README 里对应位置的 `<!-- shot:xxx -->` 换成 `![说明](docs/shots/xxx.png)`。

## 怎么截

```bash
npm run restart
```

浏览器打开 `http://127.0.0.1:8848`，按上表切到对应页面。
Windows：`Win + Shift + S` 截图，存成 `docs/shots/` 下的对应文件名。

截之前建议：

1. 把浏览器窗口拉宽到上表给的宽度（用 DevTools 的设备模拟也行）
2. 等页面动画跑完再按（进场动画 0.2s）
3. **不要**把自己的选题、正文内容留在图里 —— 换成干净的演示稿，或者自己先打码

第 3 条最重要：截图会跟着仓库公开，稿子里的东西也会跟着公开。

## 截完检查一下

```bash
node engine/shots-check.mjs
```

会检查：文件在不在、大小是不是 0、README 里引用的图有没有真的被引用。
