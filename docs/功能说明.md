# 功能说明

> 本文把写作台每一个功能摊开讲：**做什么 / 解决什么问题 / 怎么点**。
> 数字都是实测的（断言条数、动作数、主题数），不是估的。

---

## 全景：四页一圈

```
① 热点  →  ② 定题  →  ③ 成稿  →  ④ 发布
 找选题      定写什么     改稿/配图/核对   排版+复制进公众号
```

侧栏固定四步，任何时候都在，看一眼就知道走到哪儿了。

---

## ① 热点页：把「翻 App 找选题」变成一次点击

### 功能 1.1　15 个平台热榜聚合

| | |
|---|---|
| **做什么** | 同时抓 15 个平台的公开热榜，跨平台归并去重 |
| **解决什么** | 不用微博刷十分钟、知乎刷十分钟、头条刷十分钟，还怕漏掉爆款 |
| **怎么用** | 打开就是列表。想看某一家，点顶部的平台切换 |

**去重是认真的**：跨平台的同一条热搜会被合成一条，不是把 15 个榜原样堆给你。
去重键怎么定的见 [热点筛选原理.md](热点筛选原理.md)。

### 功能 1.2　4 小时缓存 + 失败回退

| | |
|---|---|
| **做什么** | 同一份榜 4 小时内不重复抓；抓不到时退回旧数据并标 `stale` |
| **解决什么** | 不打爆源站，也不让你看到空白页 |
| **怎么用** | 顶部会显示数据新鲜度。要强制重抓，命令行加 `--force` |

**宁可旧不可空** —— 一个空列表会让你以为「今天没热点」，而真相是网络抖了。

### 功能 1.3　原文预览与摘要

| | |
|---|---|
| **做什么** | 点条目自动抓原文，抽正文，生成摘要 |
| **解决什么** | 不用点进 15 个标签页一个个读 |
| **怎么用** | 点一条，右侧（或下方）自动出摘要。点「读全文」打开原页 |

**抓不到会明说**：JS 壳页面（今日头条、知乎、抖音）的正文不在 HTML 里，
工具会直接告诉你抓不到并给原页链接，而不是给你一段噪音。

### 功能 1.4　存进选题库

| | |
|---|---|
| **做什么** | 看中的条目一键存进选题库 |
| **解决什么** | 选题不再烂在收藏夹里 |
| **怎么用** | 点条目上的存按钮 → 跳到定题页，题框已填好 |

**只填题，不碰标题** —— 这条踩过两次，验收里有断言守着。

## ② 定题页：把「想写什么」变成一份可执行的委托

### 功能 2.1　选题队列 + 历史稿

| | |
|---|---|
| **做什么** | 待写的选题排队区 + 写完的历史稿列表 |
| **解决什么** | 同时想好几个题的时候不丢；写完的稿子找不回来 |
| **怎么用** | 队列区点条目填进题框；历史稿点「打开」直接回填成稿页 |

### 功能 2.2　选配图数量，生成写作任务

| | |
|---|---|
| **做什么** | 选这次要配几张图（4/6/8/10/12，默认 10），生成一段交给 AI 的写作任务 |
| **解决什么** | 每次都重新交代一遍要求 |
| **怎么用** | 填题 → 选图数 → 点提交。任务出现在队列区，复制去 AI 对话窗口 |

任务里带的东西：题目、角度、配图数量、补充要求、当前事实清单状态。

### 功能 2.3　提交去重

| | |
|---|---|
| **做什么** | 同一个任务重复提交会被拦，提示「已提交过」 |
| **解决什么** | 手滑点两下，队列里出现两条一样的 |
| **怎么用** | 改稿请走「改稿」动作 —— 它是迭代任务，不该被去重误伤 |

## ③ 成稿页：一个文框，剩下全在右边

### 功能 3.1　正文编辑 + 自动保存

| | |
|---|---|
| **做什么** | 一个文框直接改，改完自动落盘 |
| **解决什么** | 不用在编辑器和别处来回倒腾 |
| **怎么用** | 打字就走。切页回来内容在，滚动位置也在 |

**自动刷新不抢焦点**：AI 在另一端写完交稿，页面自动更新，但不会打断你正在输入。

### 功能 3.2　实时自检（不用点任何按钮）

| | |
|---|---|
| **做什么** | AI 味、来源前缀、标点硬禁、否定式、预设式、事实风险、标题配套…… 一次算完 |
| **解决什么** | 交稿前才发现「不能写不是A而是B」，重写一遍 |
| **怎么用** | 打开就在概要条上。红了点开看明细 |

自检是**现算的**，不读缓存 —— 改完正文立刻重算，不会拿上一次的结果糊弄你。

### 功能 3.3　备选标题，点一下就换

| | |
|---|---|
| **做什么** | AI 交 6 个候选标题进 `data/titles.json`，界面自动收下；点一下整条替换 |
| **解决什么** | 标题从对话窗口复制回来粘进框里，一步都不能少 |
| **怎么用** | AI 交完稿，右侧就出现 6 个候选，每条带字数。点中意的那个 |

标题硬规矩（验收守着）：**12~22 字**、最多一个断句、六条不同句式、
每条都要有数字/实体/动作/立场落点。超过 22 字的会被丢掉并明说丢了哪几条。

### 功能 3.4　事实清单分级

| | |
|---|---|
| **做什么** | 正文里的可验证断言自动列成清单，按风险分级；高危项进自检 |
| **解决什么** | 「罚款 500 万」写错一位，读者信了就是事故 |
| **怎么用** | 交付区展开「事实清单」→ 逐条标已核 / 待核。高危的会顶到自检里 |

分级规则：精确小数、量级、百分比一律高危。直接引语不算断言。

### 功能 3.5　配图：抓、选、定位

| | |
|---|---|
| **做什么** | 从原网页抓图（自动过滤二维码和站标）→ 图库存起来 → 推荐插入位置 |
| **解决什么** | 找图、配位置、调顺序，三件事开三个窗口 |
| **怎么用** | 「找配图」生成任务交给 AI，或跑 `node engine/grab-img.mjs <url>`；<br>图库展开后能看能删；「推荐插入位置」面板点一下就插 |

**位置推荐不是随机的**：按段落语义打分，避开已有图、开头结尾不配、间隔至少 2 段。

### 功能 3.6　版本对比与回滚

| | |
|---|---|
| **做什么** | 和任意历史版本做段落级 LCS 对比，区分增/删/改，可一键回滚 |
| **解决什么** | 改坏了不知道回哪一版 |
| **怎么用** | 交付区「历史稿」→ 选一版 → 对比 |

### 功能 3.7　一键改写

| | |
|---|---|
| **做什么** | 把「改写要求 + 原文」打包成一段可复制的话，去 AI 那边改 |
| **解决什么** | 每次改稿都要重新交代上下文 |
| **怎么用** | 右侧填改写要求 → 点「一键改写」→ 复制去 AI |

## ④ 发布页：11 套主题，一键复制（含图）

### 功能 4.1　11 套排版主题

| | |
|---|---|
| **做什么** | 换主题即时重排，字号/行距/文字色/强调色/纸底五项可微调 |
| **解决什么** | 在公众号编辑器里一行行抠空格 |
| **怎么用** | 左边点主题，右边立刻出效果；微调栏改数值实时生效 |

**11 套不是 11 种颜色**：每套声明唯一结构特征（首行缩进 / 悬挂缩进 / 左轴线 /
首字下沉 / 通栏大字引语 / 编号卡片…），任意两套的排版规则重合度 < 0.6。

### 功能 4.2　为中老年读者调的字

| | |
|---|---|
| **做什么** | 主题字号下限 16.5px，默认 17px / 行距 2；正文默认衬线、朱红强调 |
| **解决什么** | 公众号读者偏中老年，14px 灰字他们看不清 |
| **怎么用** | 不用调。想更松就自己往上加 |

### 功能 4.3　复制图文（含图）

| | |
|---|---|
| **做什么** | 样式内联 + 图片转 base64，一次复制进公众号，图片一起过去 |
| **解决什么** | 公众号编辑器不接受外部样式，也不肯直接吃本地图片 |
| **怎么用** | 点「复制图文（含图）」→ 去公众号粘贴 |

超 12MB 会拦下来并给「下载图片包」的出路 —— 剪贴板拒收之前就告诉你。

### 功能 4.4　下载图片包兜底

| | |
|---|---|
| **做什么** | 打包成 zip（自己实现的，无第三方依赖），含 UTF-8 文件名标记和 CRC32 |
| **解决什么** | 图太多时复制这条路走不通 |
| **怎么用** | 点「下载图片包」，解开放进公众号 |

## 横着长的能力

### 界面不是「调出来的」，是「量出来的」

[`UI设计规范.md`](../UI设计规范.md) 是一份带实测数据的规范：
间距 8 档、字号 7 档、圆角 4 档，内容离屏幕边缘至少 16px，
块外间距 ≥ 块内间距 × 3。每一个数都写着是怎么测到的、踩过什么坑。

### 检查在代码里，不在文档里

`验收测试.js`：**809 条断言、85 个分组**。不是文档里写「请注意」，是改坏了当场红。

反向验证用的都是**真实产出过的坏例子**：
比如上一轮那六条平均 31.3 字的啰嗦标题，直接写进判据当负样本。

### 热点榜可以脱离界面单独用

```bash
node engine/hot-cli.mjs --json --flat --top 30
```

纯 CLI、不依赖 server、不依赖浏览器，退出码有意义（全挂返回 1，调用方能决定要不要重试）。
写定时任务、喂给 Agent 做早报都行。
