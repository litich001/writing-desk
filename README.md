# Write Work · 写作台

**给 AI 时代个人 OPC 用的自媒体运营工作台。**

抓全网热点 → 按你的要求一键改写 → 自动配图 → 自动排版 → 一键进公众号。

作者：[李哲 Lizhe](https://www.lizhe.work) · [天行 GEO](https://aigeo.games/) 品牌主理人 · [Creator OS](https://creatoros.com.cn/) 出品人

---

## 这工具是给谁做的

一个人做自媒体，要干四件事：

| | 现实里什么样 |
|---|---|
| **选题** | 打开五个 App 刷二十分钟，还是不知道写啥 |
| **写稿** | 反复跟 AI 交代要求、改了八遍还是不对味 |
| **配图** | 找图找半小时，找到的还不能用 |
| **排版** | 在公众号编辑器里一行行抠空格，两小时 |

这四件事里，**没有一件需要你动脑子，全是在转圈**。

写作台把这四件事接过来。你只留两件事：**想写什么**、**最后那句话要不要这么说**。

---

## 四个核心功能

### 一、抓 —— 全网热点，一页看完

同时抓 **15 个平台**的公开热榜（微博、知乎、头条、百度、抖音、B 站…），
跨平台去重——同一个热搜只出现一次，不是把 15 个榜原样堆给你。

点任意一条，**自动抓原文、出摘要**，不用你点预览、不用开标签页。

- 榜单 **4 小时缓存**，不把源站打爆
- 抓取失败自动退回旧数据并标明，**宁可旧不可空**
- 看中的存进选题库，选题不再烂在收藏夹

命令行也能单独用，写早报、喂给 Agent 都行：

```bash
npx hot-cli --json --flat --top 30
```

---

### 二、改 —— 按你的要求，一键生成改写任务

你只需要**说清楚要什么**。工具把它变成一份完整的写作任务，附上：

- 你定的题目和角度
- 你要的配图数量（4 / 6 / 8 / 10 / 12 张）
- 你的补充要求
- 事实清单的核实状态

任务一键复制，粘进你平时用的 AI 对话工具（Claude / GPT / 豆包 / 任意）。
AI 写完回三样东西进 `data/`，**页面自动刷新，不用手动导入**。

交稿之后它还继续盯着：

- **实时体检正文**——AI 腔、来源前缀（「据某某报道」）、你禁的三种标点、预设式语句，改完立刻重算
- **6 个备选标题直接列在页面上**，每条标字数，点一下整条换上，不用复制粘贴
- **事实清单分级**——「罚款 500 万」写错一位就是事故，精确数字、量级、百分比一律顶到最前面
- **改稿一键打包**——填一句要求，连同原文一起复制走

**为什么模型不写死在工具里？**
因为模型三个月一换，焊死的工具跟着一起过时。
这里 AI 只通过一份手册接活——**你换什么模型都行，工具这边不用改一行**。

---

### 三、配 —— 图片素材自动采集

从原文页面直接抓图，**自动滤掉二维码和站点水印**（这两样经常是页面上最显眼的两个图），
每张图都记着它从哪来，可以回溯。

放不进去？工具按**段落语义打分**推荐插入位置：

- 避开已经有图的地方，间隔至少 2 段
- 开头结尾不配图
- 点一下就插进正文

**一张对不上的图比没有图更糟**——它让人以为这篇有现场照片。所以工具只给建议，选不选你定。

---

### 四、排 —— 11 套主题，自动排版，一键进公众号

11 套主题不是 11 种颜色，是 **11 种排版结构**：首行缩进、悬挂缩进、左轴线、
首字下沉、通栏大字引语、编号卡片……换主题，版式整个变掉。

五项微调实时生效：字号、行距、文字色、强调色、纸底。

点「复制图文（含图）」→ 粘进公众号，**样式和图片都跟着过去**。
公众号不接受外部样式，也不肯直接吃本地图片，这一步工具替你做完了。

**字号是给中老年读者调的**：主题字号下限 16.5px，默认 17px / 行距 2。
公众号读者偏中老年，14px 灰字他们看不清。

## 一篇稿子的完整流程

```
①  热点页    刷一眼，看中哪条
     ↓ 点一下
②  定题页    存进选题库，填角度，选配图数量，一键生成任务
     ↓ 复制，去 AI 对话
③  AI 写稿   按手册交正文、6 个标题、事实清单
     ↓ 写进 data/，页面自动刷新
④  成稿页    6 个标题点一下就换；核事实；配图插入
     ↓ 满意了
⑤  发布页    选主题 → 微调 → 复制图文（含图）→ 粘进公众号
     ↓
     发了
```

**全程不用切换窗口。**

## 安装

### 你需要先有 Node.js

**只要一样东西**：Node.js 20 或更新版本。

- Windows / macOS：去 <https://nodejs.org> 下载 LTS，一路下一步
- macOS 也可以 `brew install node`
- Linux：`sudo apt install nodejs npm`

装完在终端里敲 `node -v`，看到 `v20` 以上就成了。

### Windows：双击就行

下载或克隆之后，**双击 `启动.bat`**。它会自己打开浏览器。

（就是上面那个黑窗口，别关，关了服务就停。）

### macOS / Linux / 任何地方：三行命令

```bash
git clone https://github.com/litich001/writing-desk.git
cd writing-desk
npm install
npm run restart
```

浏览器打开 <http://127.0.0.1:8848>。

> `npm install` 只会装两个包（markdown-it 和 markdown-it-footnote）。
> 其余全部用 Node 自带的东西，不用数据库，不用打包，不用编译。

### 装不上？四个常见状况

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `npm 不是内部或外部命令` | 没装 Node，或者装完没重开终端 | 重开一个终端窗口再试 |
| `Cannot find module 'markdown-it'` | `npm install` 没跑或跑失败 | 在项目目录里重跑一次 `npm install` |
| 端口 8848 被占用 | 上一次没关干净 | 关掉那个黑窗口；或 `node server.mjs 8849` 换端口 |
| 页面白屏但控制台有报错 | 文件夹解压时层级压平了 | 确认目录里有 `server.mjs`、`app.js`、`data/` |

### 不联网能不能用

能。抓热点和抓图要联网，**其余全部离线可用**——写稿、改稿、排版、
导出公众号都在本机跑。

## 第一次用：三步走完第一篇稿

### 第 1 步 · 打开就是热点页

左边四步导航，当前在第 1 步。热榜已经抓好了。

### 第 2 步 · 点一条，存进选题

点任意一条 → 自动出摘要。觉得能写 → 点「存」→ 自动跳到定题页，题框已填好。

### 第 3 步 · 生成任务，复制走

选配图数量（默认 10 张）→ 提交 → 任务出现在队列区 → **复制那段文字** → 粘进你的 AI 对话工具。

## 日常怎么用

**每天的固定动作只有这几下：**

1. 打开页面，看热点列表（已经聚合好了，不用刷 App）
2. 点中一条，存进选题
3. 填角度，点提交，复制任务去 AI 那边
4. AI 交稿 → 页面自己刷新 → 点一个标题
5. 展开事实清单，把高危的数字核一遍
6. 展开图库，点「推荐插入位置」
7. 发布页选主题 → 复制图文 → 粘进公众号

**顺序不用死板**。改稿就从第 4 步进，历史稿在定题页左边点「打开」直接回填。

## 适合谁 / 不适合谁

**适合**

- 一个人做公众号、头条、小红书、知乎的个人创作者
- 一天要更 1~3 条、靠量走的内容号
- 已经在用 AI 写稿，但被「交代要求、配图、排版」这些琐事拖住的人

**不适合**

- 想要「打开就出成品」的产品——这里 AI 在你那边，工具不代劳
- 团队协作版——现在是单人本地工具，没做多人同步
- 已经有一整套成熟 CMS 的机构

## 常见问题

**热点抓不到怎么办？**
豆瓣返回 403、部分平台要 JS 渲染，工具会**明说哪个源不可用**，不会假装抓到了。
不绕过反爬——需要时手动去原站看。

**能「一键生成全文」吗？**
不能，这个工具不内置模型。它做的是**准备和收尾**：把任务组织好、
把结果接住、把中间的检查和排版跑掉。

**排版能直接进公众号吗？**
能。点「复制图文（含图）」，样式内联、图片转 base64，粘进去就是成品。
图太多超过 12MB 会拦下来，并给「下载图片包」的出路。

**数据会不会传到网上？**
不会。除了抓热点和抓图时会请求第三方站点，你的数据不出这台电脑。
不上云、不上传、不需要账号。

**换 AI 要不要改工具？**
不要。AI 只通过一份手册接活，换模型不用动这里。

**手机能用吗？**
不能。这是本地工具，手机访问不到 `127.0.0.1`。

## 给开发者

> 这一段是给要改代码的人看的。只想用工具的话，上面看完就够了。

**技术栈**：零构建。Node.js 原生服务 + 原生 ESM 前端，无框架、无打包、无 TypeScript。
两个运行依赖（markdown-it、markdown-it-footnote），其余全靠标准库。

**跑检查**：

```bash
npm test              # 820 条断言
npm run check         # 全套（含布局体检、样式、图片导出、截图检查）
npm run hot           # 只抓一次热榜看看
```

**命令一览**：

| 命令 | 干什么 |
|---|---|
| `npm run restart` | 起服务（改完代码跑这个，不跑会吃到旧内容） |
| `npm test` | 820 条断言 |
| `npm run check` | 一键全检 |
| `npm run hot:json` | 热点榜导出 JSON |
| `npm run stamp "说明"` | 打版本戳 |
| `npm run shots` | 验截图有没有断链 |

**目录**：

```
server.mjs        本地服务：静态文件 + /api（热点代理/预览/图片）
app.js / app.css  前端
engine/           60+ 个小脚本，一个脚本干一件事
data/             你的稿子，纯文本
验收测试.js        820 条断言
AI操作手册.md      给 AI 看的接活规范（改写作规则要同步改它）
UI设计规范.md      间距/字号/圆角/边缘距离，每档都写了实测数据和踩过的坑
docs/功能说明.md   19 个功能的完整说明（做什么/解决什么/怎么点）
docs/截图.md       截图清单和补法
```

**这套东西的取向**：检查写在代码里，不写在文档里。
`验收测试.js` 覆盖排版真实性、微信导出链路、标题质量、正文 AI 味、
CSS 变量悬空、布局几何等。反向验证用的都是**真实产出过的坏例子**——
比如上一轮那六条平均 31.3 字的啰嗦标题，直接写进判据当负样本。

**改写作规则要改两个地方**：提示词在 `app.js`，规范在 `AI操作手册.md`。
只改一处会漏，验收里有检查盯着这件事。

想改代码，先看 [CONTRIBUTING.md](CONTRIBUTING.md)。
